HANDTREMORMÄTARE — GitHub Pages

1. Skapa ett nytt offentligt repository på github.com/new, exempelvis handtremor.
2. Välj Add file > Upload files och ladda upp index.html, manifest.webmanifest, service-worker.js, icon-192.png och icon-512.png i repositoryts rot. (Ladda INTE upp zipfilen som zip.)
3. Gå till Settings > Pages > Build and deployment: Deploy from a branch, Branch main, folder /(root), Save.
4. När GitHub Pages visar adressen, öppna den i Chrome på telefonen. Adressen börjar med https://.
5. Tryck Testa sensorn och rör telefonen. När sensorn fungerar, Chrome-menyn > Lägg till på startskärmen > Installera (om det erbjuds).

Observera: Android och Chrome måste ha rörelsesensorfunktion aktiv. HTTPS garanterar inte åtkomst om webbläsaren blockerar sensordata.

Appen är ett experimentellt hjälpmedel och inte avsedd för medicinsk diagnos. Mätdata skickas inte till någon server.
